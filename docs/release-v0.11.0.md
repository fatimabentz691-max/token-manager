# Token Manager v0.11.0：可靠性核心版

本版本暂停扩充视觉效果，集中解决数据可信度、实时刷新、OpenCode 本地监控、首次接入与统一发布。

## 主要更新

- 每条 Token、请求、缓存、费用与余额记录都标注来源、精确度、账户、采集时间和价格版本。
- 代理请求结束后立即刷新；本地文件 500ms 防抖监听，30 秒安全补扫。
- OpenCode 自动模式优先只读 SQLite，不兼容时明确提示并回退 JSON/JSONL。
- 新增监控健康中心、数据来源徽标、首次接入向导和真实无数据引导。
- 新用户默认进入高级模式，原有简单模式、主题和悬浮窗配置保持不变。
- 新增稳定频道半自动更新；安装前同时复核安装包大小、SHA-256 与 Tauri 更新签名。
- 官网、后台、GitHub Release 与客户端更新页统一使用同一份 v2 发布清单。

## 数据边界

Codex 只有在客户端本地事件存在 `rate_limits` 时才显示客户端报告额度；否则明确标注为个人估算。普通模型 API Key 不会被冒充为官方账单权限。
