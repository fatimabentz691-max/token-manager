# Token Manager v0.11.10

## 新增功能

- 说明系统统一为“靠近时显示、始终显示、完全隐藏”三种严格模式，并提供清晰的单选分段卡与键盘操作。
- 悬浮窗数字采用可取消的平滑滚动动画，快速刷新时从当前显示值继续，不再因旧动画回写而跳动。
- 客户端心跳升级为 60 秒更新通道，可接收最新版本、更新亮点与修复摘要。
- Admin 新增匿名设备状态页，区分累计下载、累计安装设备、当前在线以及 24 小时、7 天活跃。

## 修复问题

- 修复隐藏模式仍残留普通说明、靠近一个区域导致多条说明同时出现的问题。
- 修复悬浮窗详情层被液态玻璃透出底层文字、靠近屏幕边缘时内容不清晰的问题。
- 修复数字快速连续更新时宽度抖动、旧动画覆盖新值的问题。
- 修复更新提醒只在启动时检查、后台发布后运行中的客户端无法及时收到提醒的问题。
- 修复心跳失败被静默忽略以及在线设备口径无法解释的问题；在线窗口统一为 150 秒。

## 数据边界

Token、日志和本地观测仍不会被包装成官方剩余额度。只有客户端或供应商真实返回额度字段时才展示对应额度，否则明确标注本地观测或个人估算。
