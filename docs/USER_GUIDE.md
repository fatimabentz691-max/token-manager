# Token Manager 用户使用手册

## 认识三个数据来源

Token Manager 会在界面中区分：

- **本地日志**：Codex 本机状态库和日志；
- **本地代理**：从真实 API 响应的 `usage` 字段提取 Token；
- **官方余额**：厂商明确提供并已验证的余额接口。

三者不能混为一谈。没有官方账单权限的平台会显示限制说明，而不是虚构余额。

## 添加 API 账户

1. 打开“账户与模型”。
2. 找到平台，点击“官网”创建或管理 API Key。
3. 回到软件点击“添加账户”。
4. 填写便于识别的账户名称、官方 Base URL 和 API Key。
5. 点击“加密保存账户”。

### OpenCode Go 套餐

在“账户与模型”选择 **OpenCode Go**，软件会自动填写 `https://opencode.ai/zen/go/v1`。只需粘贴 Go 订阅 API Key；保存后会调用官方 `/models` 验证密钥并读取当前模型列表。调用经过 Token Manager 本机代理后，5 小时、近 7 天和近 30 天额度卡会按官方公开模型单价统计本机已观测用量。

如果不希望改代理配置，可在 OpenCode Go 卡片选择“自动、SQLite、JSON”三种模式。自动模式优先查找 OpenCode 官方 SQLite，会以只读短连接提取会话聚合用量；数据库结构不兼容时会明确提示并回退 JSON/JSONL。文件变更通常 2 秒内进入仪表盘，监听失效时最迟 30 秒补扫；不会保存提示词、回复正文、代码或认证信息。

设置页的“监控健康”入口可查看每个数据源的实际文件、最后成功时间、下次刷新、同步延迟、本次新增事件数和最近错误。

## 安全更新

Token Manager 启动后检查稳定频道，但不会静默强制安装。用户确认后，软件先复核安装包大小和 SHA-256，再由 Tauri Updater 校验更新签名；任一校验失败都会中止。无 Windows Authenticode 证书时，安装程序仍可能显示 SmartScreen 提示。

OpenCode 当前公开文档要求在网页控制台查看官方精确用量，没有公开仅凭 API Key 返回套餐剩余百分比的接口。因此软件不会要求登录 Cookie，也不会把本机观测值标成官方余额。

同一平台可添加多个账户。账户关闭应用后仍会保留；可单独删除，也可批量清空。

## 开启 API 实时监控

1. 点击主界面右上角“一键开启 API 实时监控”。
2. 软件从 `18765` 开始为每个账户分配本机端口。
3. 复制对应账户的本机地址，例如：

```text
http://127.0.0.1:18765/v1
```

4. 在 SDK、编辑器或调用工具中，把原厂 Base URL 改成该地址。
5. API Key 可继续由 Token Manager 托管；代理会向原厂 HTTPS 地址转发。

DeepSeek‑V4‑Pro 有两种接入地址，软件会在“实时监控链路”中分别显示并提供复制按钮：

- Deep Code、OpenAI 兼容 SDK：`http://127.0.0.1:<端口>/v1`
- Claude Code、Anthropic 兼容 SDK：`http://127.0.0.1:<端口>/anthropic`

仅仅开启代理端口并不代表调用已经进入 Token Manager。状态显示“等待调用端接入”时，仍需修改调用工具的 Base URL；只有真实请求到达后才显示“正在接收”。V4 Pro 流式响应会在生成期间原样转发，并在响应完成后写入输入、输出、缓存 Token 和人民币成本。

代理只监听回环地址，不接受局域网连接。不要把 `127.0.0.1` 地址配置到另一台电脑或云服务器。

## 查看全部模型

“全部模型”页面提供：

- 今日全平台 Token、API 请求、活跃模型和成本；
- 7/30 天 Token 堆叠柱状图；
- 每个 AI 固定颜色和悬停明细；
- 模型用量排行、月度花费占比和 30 天消费趋势；
- API 代理和 CC Switch 连接状态。

Token 总量按输入与输出相加。缓存命中 Token 属于输入 Token 的一部分，不会重复相加。

## 添加单模型仪表盘

1. 先添加平台账户。
2. 打开仪表盘，点击“添加仪表盘”。
3. 从账户实际模型列表或内置目录中选择模型。
4. 新仪表盘只显示该平台、账户和模型的数据。

单模型页包含 Token、请求次数、缓存命中、成本、余额状态和四类近 7 天图表。

## Codex 专属页面

Codex 页面无需 API Key。首次使用前，在设置页填写个人 5 小时和 7 天 Token 预算。软件会依据本机日志显示预算剩余比例、滚动窗口和任务换算。

这些数字不是 ChatGPT 官方会员余额。官方客户端显示与本地估算冲突时，以官方客户端为准。

## 悬浮窗

- 在设置页点击“一键启用悬浮窗”；
- 拖动顶部空白区域移动窗口；
- 拖动右下角调整尺寸；
- 使用顶部下拉框切换模型；
- 在设置页勾选模块、拖动排序并选择两个迷你模块；
- 所有变更实时生效并自动保存。

## 主题、微光与液态玻璃

- 在“设置 → 通用显示与设置”切换主题；每套主题都有独立匹配的鼠标跟随微光颜色。
- “鼠标跟随微光”可以单独关闭，不影响图表和数据刷新；关闭全部动画时微光也会停止。
- 选择“液态玻璃”后，可以上传 PNG、JPEG 或 WebP 背景，并用色板或系统取色器修改玻璃主题色。
- 原图最大 20 MB，软件会在本机压缩后保存。图片会进入 WebGL 环境纹理并参与玻璃折射；浅色图片会自动增加玻璃承载层，避免文字失去对比度。
- 也可以选择 MP4、WebM、MOV 或 M4V 本地视频作为动态壁纸，单文件最大 1 GB。视频优先于备用图片，并逐帧参与液态玻璃折射。
- 视频正文不会复制进软件数据库或浏览器存储，只保存本机绝对路径；请勿移动或删除原文件。更换电脑后需要重新选择视频。
- 背景、主题色与开关会立即同步到主窗口、完整液态玻璃左侧栏和悬浮窗；图片配置与主题设置可随本地加密迁移包导出。

## Arena 排行榜

- 榜单直接读取 Arena 官方公开数据集，展示官方名次、Score、95% 置信区间、票数、实验室和许可证。
- 可切换综合、编程、WebDev、视觉、搜索和文档榜单；本机会每 30 分钟检查一次官方新快照。
- 界面会分别标注“本次已联网同步”“本机缓存”或“离线缓存”，缓存不会伪装成实时数据。
- 选择一个模型后会显示官方六维分类位置图：编程、数学、指令遵循、多轮对话、创意写作和长问题处理。图中是分类排名换算的位置指数，不是 Token Manager 自行生成的能力分。
- 任一维度暂时连接失败时，其余成功维度仍会展示；“同步失败”和官方“未上榜”会分开标注，缺失值不会按 0 绘图。
- 在搜索框输入模型或实验室后按 Enter，可在系统浏览器打开 Arena 官方搜索；“去 Arena 对战”会直接打开官方对战页面。

## 导出账单

报告中心可以导出 UTF-8 CSV，字段包括时间、平台、模型、输入 Token、输出 Token、缓存 Token、成本和任务类型。Excel 可以直接打开该文件。

## 更换电脑

1. 在旧电脑设置页输入至少 8 位迁移密码。
2. 导出 `.tmbak` 文件。
3. 在新电脑安装 Token Manager。
4. 输入同一密码并导入迁移包。
5. 导入后的 API Key 会重新使用新电脑当前用户的 DPAPI 加密。

请把迁移包视为敏感文件，不要上传到 Issue 或公开网盘。
