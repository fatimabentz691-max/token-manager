# Token Manager UI 验收矩阵

## 视口与窗口

| 场景 | 必查内容 |
|---|---|
| 1440×900 全屏 | 顶部操作区、侧栏固定、图表完整、监控健康不遮挡 |
| 980×760 半屏 | 顶部操作自动换行、无横向溢出、卡片不重叠、可原生滚动 |
| 100/125/150/200% DPI | 圆角裁切、窗口控制胶囊、悬浮窗四角、文字不截断 |
| 悬浮窗胶囊 | Logo、主要 Token/额度、环形指标、状态和展开键可见且可拖动 |
| 悬浮窗紧凑/完整 | 模型卡片独立、图表 tooltip、缩放/置顶/折叠/恢复交互正常 |

## 主题与材质

| 场景 | 必查内容 |
|---|---|
| 原生黑白 | `#FFFFFF/#1D1D1F/#86868B/#F2F2F7` 层级清晰，图表可读 |
| 液态深色 | 背景、侧栏、顶部条、卡片和悬浮窗统一通透度与扭曲 |
| 液态纯白 | 白色材质不使文字消失，所有表面统一透明度，圆角无残留 |
| 自定义主题色 | 只替换语义令牌，图表颜色和状态色保持可辨识 |
| GPU/捕获失败 | 降级为 Acrylic/普通半透明，绝不黑屏、白屏或失去交互 |

## 交互与数据

- 仅当前 hover 卡片显示微光；离开后清理 CSS 变量和状态。
- 图表 tooltip 必须显示真实时间、Token、请求、缓存和成本；没有数据时显示占位引导。
- 主窗口和悬浮窗使用同一 store、同一主题、同一图表颜色和同一刷新事件。
- Codex 的官方报告额度、个人估算和其他模型余额必须有不同来源标签。
- 代理请求完成后应触发即时刷新；本地文件变化应在监听窗口内反映，失败时显示健康错误并等待补扫。

保留构建输出、测试结果、全屏/半屏截图或几何检查结果。若无法执行某项测试，明确写出未验证原因，不以“看起来正常”代替证据。
