# Token Manager 设计令牌参考

## 语义令牌

| 语义 | 默认值 | 使用范围 |
|---|---|---|
| `--tm-bg` | `#FFFFFF` | 内容层、输入背景 |
| `--tm-surface` | `#F2F2F7` | 占位、次级表面、图表底 |
| `--tm-ink` | `#1D1D1F` | 标题、正文、主要控件 |
| `--tm-muted` | `#86868B` | 辅助文字、时间、来源说明 |
| `--tm-line` | `rgba(29,29,31,.10)` | 极淡分割线和边界 |
| `--tm-accent` | `#007AFF` | 主操作、选中、焦点 |
| `--tm-danger` | `#FF3B30` | 错误、额度危险预警 |
| `--tm-success` | `#34C759` | 已连接、健康、成功 |
| `--tm-glow` | 当前主题强调色 | 鼠标微光和轻微阴影 |

## 圆角与尺寸

- `--apple-radius-sm`: 10–12px，用于按钮、输入和控制。
- `--apple-radius-md`: 16px，用于普通卡片和图表。
- `--apple-radius-lg`: 20px，用于模型卡片和主模块。
- `--floating-window-radius`: 24px；胶囊模式使用 28px。
- 进度轨道、标签和排名条使用 `999px`。
- 主内容左右内边距建议 24–54px，半屏降至 24–30px；固定侧栏宽度约 210–240px。

## 材质令牌

普通浅色模式使用白色背景和极淡灰分割线，不用厚边框。液态模式统一由 `--tm-liquid-surface`、`--tm-glass-blur`、`--tm-liquid-opacity` 和 `--tm-distortion` 控制。清透模式的侧栏、顶部条、卡片、图表、窗口控制和悬浮窗必须读取同一套令牌。

## 图表令牌

图表颜色必须通过 `chartColorPreferences` 生成：第一颜色用于主系列/选中模型，其他系列按稳定模型键分配；警告只使用危险语义色。黑白主题也要保证图表线条、tooltip 和背景的对比度，不用难以辨认的浅灰线条。
