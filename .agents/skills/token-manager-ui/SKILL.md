# Token Manager UI

把 Token Manager 视为一个统一的本地 Windows AI 控制中心。任何 UI 修改都必须以本规范为约束；不要创建只在单个页面生效的孤立样式、第二套主题令牌或与主窗口分离的数据展示。

## 强制工作流

1. 先读取当前实现：`src/apple-design-system.css`、`src/apple-fonts.css`、`src/styles.css`、`src/floating.css`、`src/liquid-clear-unified.css`、`src/liquid-glass.css`、`src/liquid-transparency.css`、`src/spring-motion.css`、`src/white-mode.css`、`src/window-chrome.css`，再读取目标组件和对应的 `src/features/*Preferences.ts`。
2. 先说明这次修改涉及的页面、状态、主题和断点；确认数据字段与来源，不把估算、Token 占比或本地观测写成官方余额。
3. 优先复用现有 CSS 令牌、组件和同一数据源。新增令牌时同时更新主题覆盖、清透模式、白色模式、液态玻璃和悬浮窗规则。
4. 修改后至少执行前端构建；涉及 Rust、数据来源或窗口行为时执行对应测试。必须检查全屏和半屏，至少覆盖 1440×900 与 980×760，并检查 100%、125%、150%、200% DPI 的裁切和溢出。
5. 视觉检查通过后再交付。报告实际验证结果、真实数据边界和尚未验证的部分。

## 视觉基线

- 字体：优先 `PingFang SC`，降级 `Microsoft YaHei`、`Arial`、系统无衬线；数字和日志可使用系统等宽字体。禁止用衬线字体或页面局部字体覆盖全局字体。
- 默认主题：黑白 iOS 浅色。背景 `#FFFFFF`，正文 `#1D1D1F`，辅助文字 `#86868B`，分割线/占位 `#F2F2F7`，强调蓝 `#007AFF`，警告红 `#FF3B30`，正常绿 `#34C759`。代理、CC switch 等连接状态可以使用语义色，但不得改变整块页面的底色。
- 所有主题必须保持同一层级、间距、对比度和组件结构。彩色主题只改变令牌，不重排页面；白色液态主题仍需确保深色文字、边界和图表可读。
- 圆角：按钮 12px，输入/选择/进度条 10px，普通卡片 16px，模型主卡片 20px，弹窗 14px，胶囊悬浮窗 28px，紧凑/完整悬浮窗 24px，柱状条和环形轨道使用 999px。圆角必须同时应用于 CSS、透明 WebView 和 Windows 原生裁切，禁止出现方形外框、残留四角或双层重叠边缘。
- 层级：以留白、字号、字重和轻微阴影建立层级；不使用厚重黑边、3D、强渐变、常驻流光或大面积装饰。卡片悬停最多上浮约 1px，并只作用于当前卡片。
- 间距采用 4/8/12/16/24/32px 节奏；内容区可滚动，左侧菜单栏固定，禁止自定义滑轨替代原生鼠标滚动。

## 页面与组件规则

### 导航、窗口和响应式

- 左侧栏固定不随右侧内容滚动；品牌区域必须显示完整 Token Manager 名称和正确 Logo。
- 顶部窗口控制、监控健康、同步和实时链路不能遮挡标题。全屏内联排列；半屏时紧凑换行，不制造横向滚动。
- active 导航、全部模型和当前仪表盘只改变选中状态，不复制或混入其他模型数据。
- 所有交互控件必须有清晰的 hover、focus-visible、active、disabled 状态，并支持键盘操作。

### 模型仪表盘与图表

- 每个模型/账户仪表盘只读取自身 provider、account 和 model 数据。Codex 专属内容不得出现在 DeepSeek、OpenCode 或其他模型页面。
- 图表优先展示真实 Token、请求、缓存、成本和余额来源；无数据时显示连接引导或柔和占位，绝不绘制仿真柱形。
- 图表卡片统一圆角、浅分割线和可读对比度；鼠标悬停显示精确数字，键盘聚焦也应可查看。
- 模型颜色必须来自 `chartColorPreferences`，同一模型在主仪表盘、报告中心和悬浮窗使用同一颜色。切换时间维度不改变数据语义。
- Arena 六维图、排行榜和搜索区必须清楚展示排名、能力维度、更新时间和数据来源，不把排行榜当作本地用量。

### 悬浮窗与灵动胶囊

- 悬浮窗是 Token Manager 内置功能，与主窗口共享 EXE、SQLite、主题、透明度、扭曲、图表颜色和动画设置；不得建立第二份数据源或独立托盘程序。
- 胶囊、紧凑、完整三种布局复用同一 Vue 数据组件，仅改变密度。每个分类是独立圆角模块：全部模型、Codex 专属、Claude Code 专属和用户自定义仪表盘。
- 标题区可拖动，窗口支持调整大小、置顶、折叠和位置记忆；收起后仍能展开、拖动和恢复交互。默认鼠标滚动查看内容，不使用不可操作的滑轨。
- 悬浮窗必须裁切干净：透明背景、圆角、阴影和原生窗口区域一致，四角不能出现白色方框、黑边或未删干净的旧材质。
- 图表使用主仪表盘同一数据与配色；迷你图表只保留环形指标、单日柱状对比、余额/额度提醒和连接状态。闲置穿透不得遮挡控制区，必须有明显锁定/交互状态。

### 液态玻璃与材质

- 液态玻璃只在液态主题开启时生效；清透白、深色和主题色共用统一的全局通透度与扭曲度，不允许侧栏、顶部白条、卡片、图表和悬浮窗各自使用不同透明度。
- 背景层可使用图片或视频壁纸；内容层保持清晰，不参与扭曲。GPU/捕获不可用时依次降级 Acrylic、普通半透明，禁止黑屏、白屏或不可读文字。
- 外窗、模型卡片、KPI/状态区可使用不同折射强度，但必须由全局参数统一缩放。顶部白条、窗口控制胶囊和悬浮窗也必须响应同一扭曲设置。
- 液态表面可以有克制的高光、模糊和背景位移；禁止叠加第二层 DOM `backdrop-filter` 造成重影、透明残留或材质不一致。

### 动效与微交互

- 默认使用 0.16–0.35s 的系统式缓动：面板淡入淡出、数字滚动、图表绘制、开关滑动、悬浮窗展开收起和轻微卡片上浮。
- 鼠标微光只作用于当前命中的卡片；移动到下一个卡片时清理前一个卡片的光效。点击粒子/成功微光必须轻量、短暂、可关闭，不能常驻循环。
- 保留全局动画开关和 `prefers-reduced-motion`；关闭后取消动画、粒子和持续采样，但不能隐藏功能或破坏布局。
- 禁止大幅位移、弹跳翻转、爆炸粒子、彩虹流光、常驻循环动画和高 GPU 占用的后台效果。

## 数据和文案边界

- 余额、Token、成本、额度和百分比必须显示来源、最后更新时间和过期状态；“个人估算”不能写成“官方余额”。
- 代理状态应说明“已接入/未接入/降级/最近成功时间”；CC switch 状态使用官方 Logo 和清晰语义，不用廉价的整块红绿背景。
- 同步中、无数据、路径不存在、权限不足、接口限流、渲染降级都要有明确状态卡和下一步操作。

## 验收清单

- [ ] 全屏与半屏无遮挡、横向溢出和标题截断；侧栏固定且内容区正常滚动。
- [ ] 100/125/150/200% DPI 下圆角无方框、残线、重影和错误裁切。
- [ ] 当前页面只显示当前模型数据；空数据没有仿真图。
- [ ] 主题、透明度、扭曲、图表颜色和动画设置在主窗口与悬浮窗即时同步。
- [ ] hover 微光只命中一个卡片；focus-visible、键盘、减少动效模式可用。
- [ ] 真实数据 tooltip 显示 Token、请求、缓存、成本和时间；来源徽标与更新时间准确。
- [ ] 液态玻璃失败时安全降级，文字仍清晰，窗口仍可拖动、缩放、关闭。
- [ ] `npm.cmd run build` 通过；Rust/UI 相关测试通过；截图或自动化几何检查留存证据。
